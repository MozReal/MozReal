# 📒 สมุดคุมเลขสารบรรณ

ระบบ **สมุดคุมเลขรับ – เลขส่ง** และ **สมุดคุมเลขรับคำร้องทั่วไป** สำหรับหน่วยงานราชการ

ติดตั้งได้ 2 แบบ ใช้หน้าเว็บและความสามารถชุดเดียวกัน:

| แบบ | เหมาะกับ | คู่มือ |
|---|---|---|
| **Google Apps Script** (แนะนำ) | หน่วยงานที่ไม่มีเซิร์ฟเวอร์ ใช้ Google Sheets เป็นฐานข้อมูล ไม่มีค่าใช้จ่าย | [gas/README.md](gas/README.md) |
| **Node.js** | มีเครื่องเซิร์ฟเวอร์/คอมพิวเตอร์ในสำนักงานที่เปิดตลอด | ด้านล่าง |

ใช้ผ่านเว็บเบราว์เซอร์ได้ทั้งคอมพิวเตอร์และมือถือ และแจ้งเตือนผ่าน Telegram Bot

- ไม่ต้องติดตั้งฐานข้อมูลแยก (ใช้ SQLite ในตัว Node.js)
- ไม่มี dependency ภายนอก จึงไม่ต้องรัน `npm install`

## ความสามารถ

| หมวด | รายละเอียด |
|---|---|
| สมุดแยกเล่ม แยกเลข | ทะเบียนหนังสือรับ / ทะเบียนหนังสือส่ง / สมุดคุมเลขรับคำร้องทั่วไป แต่ละเล่มนับเลขของตัวเอง สร้างเพิ่มได้ไม่จำกัด และเปิดเล่มปีใหม่ (เริ่มเลข 1) ได้ด้วยคลิกเดียว |
| ออกเลขทันที | กรอกรายละเอียดแล้วได้เลขทันที ทะเบียนส่งจะต่อรหัส "ที่" ให้อัตโนมัติ เช่น `ปท 72403/1235` |
| ส่งเรื่องเดียวกันถึงหลายราย | ทะเบียนส่งพิมพ์ผู้รับ 1 บรรทัดต่อ 1 ราย แล้วระบบออกเลขเรียงกันให้ทุกราย ส่วนช่อง "จาก" และ "การปฏิบัติ" จะกรอกค่าจากรายการล่าสุดให้ และทุกช่องมีรายการแนะนำจากข้อมูลที่เคยกรอก |
| จองเลข | เลือกจำนวนเลข (1–20) และลงชื่อผู้จอง ระบบล็อกเลขล่าสุดตามวันที่จอง แล้วค่อยกรอกรายละเอียดภายหลังได้ **โดยไม่นับเป็นการแก้ไข** |
| จุดแดงแจ้งเตือน | แสดงเลขที่จองค้างและยังไม่ลงรายละเอียดที่เมนู สมุด และการ์ด (แสดงในระบบอย่างเดียว ไม่ส่งทางบอท) |
| เซ็นรับหนังสือ | ทะเบียนรับมีแผ่นเซ็นชื่อด้วยลายมือจริง (นิ้ว / ปากกา stylus / เมาส์) ให้ผู้รับหนังสือภายในเซ็นรับจากฝ่ายธุรการ เซ็นได้หลายคนต่อเรื่อง และแสดงลายเซ็นในทะเบียนที่พิมพ์ |
| ประวัติการแก้ไข | ทุกรายการมี timeline บันทึกการออกเลข จอง ลงรายละเอียด แก้ไข (บอกค่าเดิมและค่าใหม่) ยกเลิก และเซ็นรับ |
| Telegram Bot | แจ้งเลขล่าสุดของทุกเล่มทุกวัน **จันทร์–ศุกร์ เวลา 08:30** (ตั้งเวลาเองได้ และกำหนดวันหยุดราชการที่ข้ามได้) พร้อมปุ่มลิงก์ **จองเลข** ของแต่ละเล่ม |
| สมัครสมาชิก | สมัครเองได้ แต่ต้องให้ผู้ดูแลอนุมัติก่อนใช้งาน |
| ผู้ดูแลระบบด้วย PIN | **ไม่มีบัญชีแอดมินเริ่มต้น** ระบบให้ตั้ง PIN ตอนเปิดใช้ครั้งแรก การปลดล็อกมีอายุ 30 นาที และถ้าใส่ PIN ผิด 5 ครั้งจะล็อก 5 นาที มีแท็บ ภาพรวม (สถิติ เลขจองค้างทั้งระบบ ประวัติการใช้งาน) / สมาชิก / สมุดทะเบียน / แจ้งเตือน Telegram / ระบบและอัพเดต |
| อัพเดตรอคำสั่งแอดมิน | ระบบตรวจหาเวอร์ชันใหม่ทุกวันแล้วพักไว้รอ (แจ้งทาง Telegram ได้) และจะติดตั้งก็ต่อเมื่อแอดมินกดยืนยัน โดยสำรองฐานข้อมูลอัตโนมัติก่อนติดตั้ง |
| ธีม + เสียงคลิก | ธีมทั่วไป 8 แบบ (สว่าง/มืด) เสียงคลิก 4 แบบ ปรับระดับเสียงได้ ทุกธีมมีเอฟเฟกต์แสงเงาและแสงตามเมาส์ |
| ธีมเทศกาล | ปีใหม่ วันเด็ก วาเลนไทน์ ตรุษจีน สงกรานต์ วันแม่ ฮาโลวีน ลอยกระทง วันพ่อ และคริสต์มาส ธีมเปลี่ยนเองก่อนถึงวันเทศกาล 7 วัน และกลับเป็นธีมเดิมเมื่อจบวันเทศกาล |
| พิมพ์ / ส่งออก | พิมพ์ทะเบียนตามแบบสมุดจริง โดยมีหัว "ทะเบียนหนังสือส่ง" และ "วันที่ … เดือน … พ.ศ. …" แยกตามวัน คอลัมน์ เลขทะเบียนส่ง / ที่ / ลงวันที่ / จาก / ถึง / เรื่อง / การปฏิบัติ / หมายเหตุ (A4 แนวนอน ฟอนต์ Sarabun) และส่งออก CSV เพื่อเปิดใน Excel ได้ |

## ติดตั้งและเปิดใช้งาน

ต้องใช้ **Node.js 22.13 ขึ้นไป** (แนะนำ 22 LTS หรือ 24)

```bash
git clone https://github.com/MozReal/MozReal.git saraban
cd saraban
npm start            # เปิดที่ http://localhost:3000
```

- เปลี่ยนพอร์ตได้ด้วย `PORT=8080 npm start`
- ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (git ไม่ติดตามโฟลเดอร์นี้ จึงไม่หายตอนอัพเดต)
- `npm start` รันผ่าน `launcher.js` ซึ่งรีสตาร์ทระบบเองหลังติดตั้งอัพเดตหรือเมื่อโปรแกรมล้ม
- **ตั้งค่าครั้งแรก:** เปิดเว็บแล้วระบบจะให้กรอกชื่อหน่วยงานและตั้ง PIN ผู้ดูแล (ตัวเลข 6–8 หลัก) จากนั้นจะสร้างสมุดของปีปัจจุบันให้ทั้ง 3 เล่ม

### ให้ระบบเปิดเองตอนเปิดเครื่อง

- **Windows:** สร้างไฟล์ `start.bat` ที่มีบรรทัด `cd /d C:\saraban && npm start` แล้ววางไว้ใน Startup หรือตั้งเป็น Task Scheduler
- **Linux (systemd):** สร้าง service ที่ใช้ `ExecStart=/usr/bin/node /opt/saraban/launcher.js` และ `Restart=always`

## ตั้งค่า Telegram

1. คุยกับ [@BotFather](https://t.me/BotFather) เพื่อสร้างบอท แล้วคัดลอก **Bot Token**
2. เพิ่มบอทเข้ากลุ่ม Telegram ของหน่วยงาน แล้วพิมพ์ `/start` ในกลุ่ม
3. ไปที่ **ผู้ดูแลระบบ → แจ้งเตือน Telegram** ใส่ Token แล้วกด **ค้นหา** เพื่อเลือกกลุ่ม (ระบบใส่ Chat ID ให้เอง)
4. ใส่ **ที่อยู่เว็บของระบบ** ที่เปิดได้จากมือถือ เช่น `https://saraban.example.go.th` เพื่อให้ปุ่ม "จองเลข" ในข้อความใช้งานได้
5. กด **ทดสอบการเชื่อมต่อ** และดูตัวอย่างข้อความได้ทางด้านขวา

> Telegram ไม่ยอมรับปุ่มลิงก์ที่เป็น `localhost` ถ้าใช้ที่อยู่แบบนี้ ระบบจะส่งลิงก์เป็นข้อความแทนปุ่มให้อัตโนมัติ

## ระบบอัพเดต

- ทุกวันตอน 07:00 ระบบจะรัน `git fetch` แล้วพักรายการเวอร์ชันใหม่ไว้ที่ **ผู้ดูแลระบบ → ระบบและอัพเดต** (ถ้าเปิดไว้ จะแจ้งทาง Telegram ด้วย)
- เมื่อแอดมินกด **ติดตั้งอัพเดตตอนนี้** ระบบจะทำตามลำดับนี้:
  1. สำรองฐานข้อมูลไปที่ `data/backups/`
  2. รัน `git pull --ff-only`
  3. รีสตาร์ท แล้วรัน migration ของฐานข้อมูลเอง
- ถ้ามีคนแก้ไฟล์ระบบในเครื่อง ระบบจะไม่ติดตั้งอัพเดตอัตโนมัติ เพื่อป้องกันไฟล์เสียหาย

## เงื่อนไขที่ตรวจแล้วว่าทำงานร่วมกันได้

- **ไม่มีแอดมินเริ่มต้น แต่สมาชิกต้องรออนุมัติ** — ผู้ติดตั้งตั้ง PIN ตอนเปิดใช้ครั้งแรก และใช้ PIN อนุมัติสมาชิกคนแรกได้โดยไม่ต้องมีบัญชีสมาชิก
- **การจองล็อกเลขตามวันที่จอง** — ตอนกรอกรายละเอียดภายหลัง ระบบคงวันที่เดิมไว้และไม่เพิ่มตัวนับการแก้ไข ลำดับเลขกับวันที่ในทะเบียนจึงยังเรียงต่อกัน
- **ออกเลขทันทีกับจองเลขใช้ตัวนับเดียวกัน** — แต่ละเล่มนับเลขภายใน transaction จึงไม่มีเลขซ้ำแม้หลายคนกดพร้อมกัน ถ้ามีคนจองตัดหน้าระหว่างกดลิงก์จาก Telegram ระบบจะให้เลขถัดไปแทน
- **เลขที่ยกเลิกจะไม่นำกลับมาใช้** (ตามหลักงานสารบรรณ) ทะเบียนจะแสดงสถานะ "ยกเลิก" พร้อมเหตุผล ผู้จองยกเลิกเลขที่ยังไม่ลงรายละเอียดได้เอง แต่เลขที่ลงรายละเอียดแล้วต้องให้แอดมินยกเลิก
- **จุดแดงเลขจองค้างไม่ส่งไปทางบอท** — ข้อความ 08:30 จะมีเฉพาะเลขล่าสุด เลขถัดไป และปุ่มจองเลข
- **ธีมเทศกาลที่ช่วงเวลาทับกัน** (เช่น คริสต์มาสกับปีใหม่) — ระบบเลือกเทศกาลที่ถึงวันแล้วก่อน ถ้ายังไม่มีเทศกาลไหนถึงวัน จะเลือกเทศกาลที่ใกล้ที่สุด ผู้ใช้ปิดธีมเทศกาลเฉพาะของตัวเองได้ และแอดมินปิดทั้งระบบหรือบังคับธีมได้
- **ขึ้นปีใหม่** — ระเบียบงานสารบรรณให้เริ่มเลขใหม่ทุกปีปฏิทิน ระบบจึงเตือนที่การ์ดสมุด และแอดมินกด "เปิดเล่มปีใหม่" ได้ (เล่มเก่ายังเปิดดูได้)
- **แจ้งเตือนเฉพาะจันทร์–ศุกร์** — ถ้าเครื่องเปิดสายกว่าเวลาที่ตั้ง ระบบยังส่งย้อนหลังได้ภายใน 2 ชั่วโมงครึ่ง และส่งวันละครั้งเท่านั้น

> วันลอยกระทงและตรุษจีนใช้ตารางวันที่ล่วงหน้าใน `public/js/shared/festivals.js` (ถึงปี 2030 และ 2035 ตามลำดับ) ถ้าต้องการปีถัดไปให้เพิ่มวันที่ในไฟล์นี้

## โครงสร้าง

```
launcher.js            ตัวเรียกเซิร์ฟเวอร์ + รีสตาร์ทหลังอัพเดต
server/
  index.js             HTTP server + ไฟล์หน้าเว็บ
  api.js               REST API ทั้งหมด
  ledger.js            ตรรกะออกเลข/จองเลข/ลงรายละเอียด/เซ็นรับ
  auth.js              สมาชิก, session, PIN ผู้ดูแล
  telegram.js          ข้อความและการส่ง Telegram
  scheduler.js         ตัวตั้งเวลาแจ้งเตือน 08:30 และตรวจอัพเดต
  updater.js           ระบบอัพเดตผ่าน git
  db.js                SQLite + migration
public/
  index.html, css/app.css
  js/app.js            หน้าเว็บทั้งหมด (SPA)
  js/themes.js         ธีมทั่วไปและธีมเทศกาล
  js/effects.js        แสงตามเมาส์ + อนุภาคธีมเทศกาล
  js/sound.js          เสียงคลิก (WebAudio)
  js/signature.js      แผ่นเซ็นชื่อ
  js/shared/           โค้ดที่ฝั่งเซิร์ฟเวอร์และเบราว์เซอร์ใช้ร่วมกัน (โครงสร้างสมุด, วันที่ไทย, เทศกาล)
test/                  ชุดทดสอบ (npm test)
```

# สมุดคุมเลขสารบรรณ — ติดตั้งบน Google Apps Script

เวอร์ชันนี้ทำงานบน Google ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

- **ฐานข้อมูล:** Google Sheets (1 แท็บต่อ 1 ตาราง: สมาชิก สมุด รายการเลข ประวัติ ลายเซ็น)
- **หน้าเว็บ:** เว็บแอปของ Apps Script เปิดได้ทั้งคอมพิวเตอร์และมือถือ
- **แจ้งเตือน:** Telegram ทุกวันจันทร์–ศุกร์ 08:30 ผ่านตัวตั้งเวลา (trigger) ของ Apps Script
- **ความสามารถ:** ครบเหมือนเวอร์ชัน Node.js ได้แก่ ออกเลข/จองเลข เซ็นรับ จุดแดง ระบบผู้ดูแลด้วย PIN อัพเดตรอผู้ดูแลยืนยัน ธีมเทศกาล และเสียงคลิก

ไฟล์ที่ต้องใช้อยู่ในโฟลเดอร์ [`dist/`](dist) มี 3 ไฟล์:

| ไฟล์ | วางเป็น |
|---|---|
| `Code.gs` | ไฟล์สคริปต์ `Code.gs` |
| `Index.html` | ไฟล์ HTML ชื่อ `Index` |
| `appsscript.json` | ไฟล์ manifest |

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)

1. ใช้บัญชี Google ของหน่วยงานสร้าง **Google Sheets ใหม่** ตั้งชื่อเช่น "สมุดคุมเลข อบต." ไฟล์นี้จะเป็นฐานข้อมูล
2. ในชีตนั้นไปที่เมนู **ส่วนขยาย → Apps Script**
3. ที่ **การตั้งค่าโปรเจ็กต์** (ไอคอนเฟือง) ติ๊ก **"แสดงไฟล์ Manifest 'appsscript.json' ในเครื่องมือแก้ไข"**
4. กลับไปที่ **เครื่องมือแก้ไข** แล้ววางไฟล์ทั้ง 3:
   - เปิด `appsscript.json` ลบเนื้อหาเดิมทั้งหมด แล้ววางเนื้อหาจาก `dist/appsscript.json`
   - เปิด `Code.gs` ลบเนื้อหาเดิมทั้งหมด แล้ววางเนื้อหาจาก `dist/Code.gs`
   - กด **＋ → HTML** ตั้งชื่อ `Index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาจาก `dist/Index.html`
   - กดบันทึก
5. กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้** แล้วกดอนุญาตสิทธิ์ (ถ้ามีหน้าเตือน "Google ไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจ็กต์)
6. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) แล้วเปิดในเบราว์เซอร์
7. หน้า **ตั้งค่าครั้งแรก** จะขึ้นมา ให้กรอกชื่อหน่วยงานและตั้ง **PIN ผู้ดูแล** (ตัวเลข 6–8 หลัก) จากนั้นระบบจะทำ 3 อย่างให้เอง:
   - สร้างแท็บฐานข้อมูล
   - สร้างสมุดของปีปัจจุบันครบ 3 เล่ม
   - ติดตั้งตัวตั้งเวลาแจ้งเตือน
8. ส่งลิงก์เว็บแอปให้เจ้าหน้าที่ ให้แต่ละคน **สมัครสมาชิก** แล้วผู้ดูแลอนุมัติที่ **ผู้ดูแลระบบ → สมาชิก**

> เจ้าหน้าที่ไม่ต้องมีบัญชี Google เพราะระบบใช้บัญชีสมาชิกของตัวเอง ที่ต้องเลือก "ทุกคน" ในขั้นตอนที่ 5 ก็เพราะเหตุนี้ และคนที่ยังไม่ได้รับอนุมัติจะเข้าดูข้อมูลไม่ได้

## ระบบผู้ดูแล (PIN)

- **ไม่มีบัญชีแอดมินเริ่มต้น** ผู้ที่รู้ PIN จะปลดล็อกได้จากเมนู **ผู้ดูแลระบบ (PIN)** แม้ยังไม่ได้เข้าสู่ระบบสมาชิก
- สิทธิ์ผู้ดูแลจะล็อกเองเมื่อไม่ใช้งาน 30 นาที ถ้าใส่ PIN ผิด 5 ครั้งจะล็อก 5 นาที
- เมนูของผู้ดูแลมี 5 แท็บ:
  - **ภาพรวม:** สถิติ เลขจองค้างทั้งระบบ (บอกว่าค้างกี่วัน) ประวัติการใช้งานล่าสุด และสถานะ Telegram/อัพเดต
  - **สมาชิก:** อนุมัติ/ไม่อนุมัติ ระงับ เปิดใช้งาน รีเซ็ตรหัสผ่าน ลบ
  - **สมุดทะเบียน:** สร้าง แก้ไข ตั้งรหัส "ที่" (เช่น `ปท 72403/`) เลขเริ่มต้น เปิดเล่มปีใหม่ ปิดเล่ม
  - **แจ้งเตือน Telegram:** ตั้งบอท เวลาแจ้งเตือน วันหยุดราชการ ทดสอบส่ง และติดตั้งตัวตั้งเวลาใหม่
  - **ระบบและอัพเดต:** ชื่อหน่วยงาน ธีมเทศกาล เปลี่ยน PIN สำรองข้อมูล เปิดฐานข้อมูลใน Google Sheets และติดตั้งอัพเดต
- ผู้ดูแลยกเลิกเลข แก้ไข และลบลายเซ็นได้ทุกรายการ โดยระบบบันทึกประวัติทุกครั้ง

## ตั้งค่า Telegram

1. สร้างบอทกับ [@BotFather](https://t.me/BotFather) แล้วคัดลอก Token
2. เพิ่มบอทเข้ากลุ่ม Telegram ของหน่วยงาน แล้วพิมพ์ `/start` ในกลุ่ม
3. ไปที่ **ผู้ดูแลระบบ → แจ้งเตือน Telegram** ใส่ Token แล้วกด **ค้นหา** เพื่อเลือกกลุ่ม จากนั้นกด **บันทึก**
4. กด **ทดสอบการเชื่อมต่อ**

ปุ่ม "จองเลข" ในข้อความจะลิงก์ไปที่เว็บแอปให้อัตโนมัติ ถ้าลิงก์ไม่ตรงกับ URL `/exec` ที่ใช้งานจริง ให้ใส่ URL นั้นในช่อง **ที่อยู่เว็บของระบบ**

## ระบบอัพเดต (รอผู้ดูแลยืนยัน)

เว็บแอปผูกกับ **เวอร์ชัน** ของสคริปต์ที่ระบุไว้ เมื่อผู้พัฒนาส่งโค้ดใหม่ขึ้นไปและสร้างเวอร์ชันใหม่ เว็บแอปจะยังใช้เวอร์ชันเดิมต่อไป จนกว่าผู้ดูแลจะกด **ติดตั้งอัพเดตตอนนี้**

- **ต้องตั้งค่าก่อน 1 ครั้ง:** เจ้าของสคริปต์เปิด **Google Apps Script API** ที่ https://script.google.com/home/usersettings
- **ระบบตรวจหาเวอร์ชันใหม่ทุกเช้า:** ถ้าพบจะขึ้นรอในหน้า **ระบบและอัพเดต** และแจ้งทาง Telegram (ถ้าเปิดไว้)
- **เมื่อผู้ดูแลกดติดตั้ง:** ระบบสร้างสำเนาสำรอง Google Sheets ก่อน แล้วจึงเปลี่ยนเว็บแอปไปใช้เวอร์ชันใหม่ จากนั้นให้รีเฟรชหน้าเว็บ
- **วิธีส่งเวอร์ชันใหม่ขึ้นไปรอ:**
  - **ผ่าน clasp:**
    ```bash
    npm run build:gas
    cd gas/dist && clasp push && clasp version "คำอธิบายการเปลี่ยนแปลง"
    ```
  - **ผ่านหน้าเว็บ Apps Script:** วางโค้ดใหม่แล้วกดบันทึก จากนั้นสร้าง "การทำให้ใช้งานได้รายการใหม่" แยกต่างหาก (เช่น ชื่อ "ทดสอบ") เพื่อให้เกิดเวอร์ชันใหม่ **ห้ามแก้ไขการทำให้ใช้งานได้ตัวหลักเอง** แล้วให้ผู้ดูแลกดติดตั้งจากในระบบ
- ถ้าระบบหา deployment หลักไม่ถูก ให้เพิ่ม Script Property ชื่อ `deploymentId` ที่ **การตั้งค่าโปรเจ็กต์ → คุณสมบัติของสคริปต์** ค่าคือรหัสในลิงก์ `https://script.google.com/macros/s/<รหัสนี้>/exec`
- เมื่อมีคอลัมน์ใหม่ในเวอร์ชันถัดไป ระบบจะเพิ่มคอลัมน์ในชีตให้เอง และข้อมูลเดิมไม่หาย

## ข้อควรรู้

- **อย่าแก้หรือเรียงลำดับข้อมูลในแท็บ** `Users`, `Books`, `Entries`, `Logs`, `Signatures` ด้วยมือ ให้ดูข้อมูลได้อย่างเดียว ถ้าต้องการวิเคราะห์ ให้สร้างแท็บใหม่แล้วใช้สูตรอ้างอิง
- ระบบใช้ LockService กันเลขซ้ำเมื่อหลายคนกดออกเลขพร้อมกัน
- Apps Script ตอบสนองช้ากว่าเซิร์ฟเวอร์ปกติเล็กน้อย (ประมาณ 0.5–2 วินาทีต่อคำสั่ง) ซึ่งเป็นธรรมชาติของ Google
- ตัวตั้งเวลาทำงานในชื่อของเจ้าของสคริปต์ ถ้าเปลี่ยนเจ้าของ ให้กด **ติดตั้งตัวตั้งเวลาใหม่** ในหน้าแจ้งเตือน Telegram
- ถ้ามีรายการเลขหลายหมื่นแถว แนะนำให้เปิดเล่มปีใหม่ แล้วย้ายข้อมูลปีเก่าไปเก็บในไฟล์อื่น

## สำหรับผู้พัฒนา

ซอร์สใช้ร่วมกับเวอร์ชัน Node.js:

- **หน้าเว็บ:** `public/` (สคริปต์ build จะรวมทุกโมดูลเป็นไฟล์เดียว)
- **ส่วนที่ใช้ร่วมกันทั้งสองฝั่ง:** `public/js/shared/` (โครงสร้างสมุด วันที่ไทย เทศกาล)
- **ฝั่งเซิร์ฟเวอร์ Apps Script:** `gas/server/*.js`

```bash
npm run build:gas   # สร้าง gas/dist ใหม่
npm test            # ทดสอบทั้ง Node.js และ Apps Script (ผ่านตัวจำลองใน gas/test/gas-mock.cjs)
node gas/test/gas-mock.cjs 3222   # เปิดเว็บแอปจำลองที่ http://localhost:3222 เพื่อดูหน้าจอ
```
